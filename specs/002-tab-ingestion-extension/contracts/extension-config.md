# Contract: extension configuration and manifest

## Build-time configuration

Read by `apps/extension/vite.config.ts` from `apps/extension/.env` at build time and inlined into the bundle. No settings screen (FR-012; spec, clarification Q4).

| Variable | Required | Purpose | Example |
| --- | --- | --- | --- |
| `VITE_API_BASE_URL` | yes | Origin the extension sends batches to, no trailing slash | `http://localhost:8787` (stub receiver), later the deployed API |
| `VITE_DEVICE_TOKEN` | yes | Bearer token identifying the device's user. A manually supplied development value until feature 003's pairing exists | blank in git |

Rules:

- `apps/extension/.env` is gitignored (`apps/*/.env*`). A committed `apps/extension/.env.example` lists both variables with **blank values**. The root `.gitignore` gains `!apps/*/.env.example` so that file is tracked.
- If either variable is empty at runtime, the extension does not send anything, sets the status badge, and logs one warning.
- The token is embedded in the built extension. `dist/` is already gitignored and must not be shared. A build with a real token is for development only.
- This feature MUST NOT read any other environment variable.

## Manifest contract

The manifest is generated by `apps/extension/manifest.config.ts`.

| Key | Value | Why |
| --- | --- | --- |
| `manifest_version` | `3` | Constitution stack row |
| `background` | `{ "service_worker": "src/background.ts", "type": "module" }` | Ingestion worker |
| `permissions` | `["storage", "alarms", "scripting"]` | Durable backlog, 30-second heartbeat, snippet capture |
| `host_permissions` | `["http://*/*", "https://*/*"]` | Read `url`/`title` and page text on web pages; reach the API without CORS. Excludes internal and extension pages by construction |
| `incognito` | `"not_allowed"` | Never enabled in incognito (code also checks `tab.incognito`) |
| `action` | `{ "default_title": "AI Browser sync" }` with no popup | Status badge only |

Forbidden in this feature (fail review if present): `chrome_url_overrides` (Home, feature 005), `side_panel` and `sidePanel` permission (Sidebar, feature 006), `tabs`, `activeTab`, `<all_urls>`, `unlimitedStorage`, `content_scripts`, `web_accessible_resources`, and any UI page.

## Status badge

| State | Badge |
| --- | --- |
| `idle`, `ok` | none |
| `retrying` | `…` |
| `auth_failed`, `misconfigured` | `!` (red). Fix `.env` or the token, rebuild, and reload the extension (or restart the browser) to resume; nothing is dropped meanwhile |
