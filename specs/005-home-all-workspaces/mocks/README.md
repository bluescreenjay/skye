# Home visual source of truth

The folder `home-design-prototype/` is the layout to implement for **feature 005**.

- Open `home-design-prototype/index.html` — default view is Home (`data-view="home"`).
- Match that Home: icon rail, wordmark, url field, greeting, workspace cards.
- The prototype’s second view (rail + workspace panel + page) is **not** 005. It belongs to the Chrome sidebar feature.

`design.txt` and `design_prompt.txt` are the original notes. If they disagree with the running prototype, the prototype wins.
